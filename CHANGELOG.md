# Changelog

## 1.1

- Add a mod icon to the NeoForge mod list.
- Native KubeJS builders for arcane shaped/shapeless crafting, crucible,
  infusion, infusion enchantments, and three Salis Mundus transformation formats.
- Edit loaded recipes with standard KubeJS filters and item replacements.
- Set individual aspect costs, scale costs in bulk, and adjust vis or instability
  while preserving research gates and unrelated recipe fields.
- Add, replace, or remove infernal furnace bonuses through Thaumaturge's data map.
- Add practical JavaScript examples and English/Russian guides for research
  and recipes, using direct calls and descriptive `kubejs:` IDs.
- Remove TypeScript declarations, editor configuration, and Node/TypeScript CI steps.
- Keep the two-version NeoForge build/GameTest matrix and automatic GitHub releases.
