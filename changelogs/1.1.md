# KubeThaum 1.1

Create and rebalance magical recipes alongside your research, with practical
JavaScript examples for everyday modpack changes.

## Added

- Recipe builders for shaped and shapeless arcane crafting, crucible recipes,
  infusion, infusion enchantments, and all three Salis Mundus transformation types.
- Infernal furnace bonus controls: add, replace, or remove bonus drops and set
  their quantities and chances.
- `/kubethaum check` to check saved research scripts without applying changes
  or restarting the world.
- A mod icon for the NeoForge mod list.

## Improved

- Standard KubeJS filters and item replacements work with Thaumaturge recipes.
- Aspect costs can be adjusted individually or scaled together. Vis and
  instability can be changed while preserving research gates and other fields.
- Research and recipe guides in Russian and English use concrete modpack tasks,
  direct calls, and descriptive `kubejs:` IDs.
- Release notes live in separate files for each version. Republishing the same
  version refreshes its files; a new version keeps earlier releases available.

## Removed

- TypeScript declarations, editor configuration, and TypeScript build checks.
