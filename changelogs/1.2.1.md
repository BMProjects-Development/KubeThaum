# KubeThaum 1.2.1

## Fixed

- KubeJS `26.1.2-8.0.7` is now accepted by the mod's dependency metadata.
  KubeJS `26.1.2-8.0.6` remains supported.
- Updated the default development dependencies to KubeJS 8.0.7 and NeoForge
  `26.1.2.115`. KubeJS 8.0.7 itself requires NeoForge `26.1.2.110` or newer;
  use KubeJS 8.0.6 if staying on NeoForge `26.1.2.109`.

## Development

- Build and GameTest checks cover KubeJS 8.0.6 on NeoForge `.109` and `.115`,
  and KubeJS 8.0.7 on NeoForge `.110` and `.115`.
- Compatibility checks verify that the registry-loading workaround for KubeJS
  8.0.6 leaves the upstream fix in 8.0.7 unchanged.
