# KubeThaum 1.2.2

## Fixed

- Removed the upper version limit for KubeJS: the dependency range is now
  `[26.1.2-8.0.6,)`. KubeJS 8.0.8 and future updates are no longer blocked
  by KubeThaum's dependency metadata. The minimum version remains unchanged.
- Future KubeJS versions are accepted assuming upstream API compatibility.

## Development

- Updated the pinned KubeJS build dependency to `26.1.2-8.0.8`.
- Simplified CI to one build using the dependencies in `gradle.properties`,
  removing the NeoForge/KubeJS version matrix. Java checks, GameTests,
  release validation, and automated publishing remain in place.
