# KubeThaum 1.3 for Minecraft 1.21.1

- Requires the Thaumaturge 1.1 series. Install the [official CurseForge release](https://www.curseforge.com/minecraft/mc-mods/thaumaturge/files/9452543) alongside KubeThaum and KubeJS.
- Added `event.recipes.thaumaturge.runic_augment(displayCatalyst, components,
  perLevel, aspects)` for runic shielding. Scripts can set research gates,
  adjust essentia costs, and replace both base and per-level ingredients.
- Research parents and requirements accept the projectile progress flags
  `thaumaturge:f_arrow`, `thaumaturge:f_fireball`, and `thaumaturge:f_spit`.
