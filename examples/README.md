# Примеры KubeThaum

В `standalone` находятся независимые примеры. Выберите нужную папку и перенесите
содержимое её `server_scripts` в `kubejs/server_scripts/`. Для примера вкладки
перенесите также `client_scripts` в `kubejs/client_scripts/` на клиенте.
После изменения исследований заново откройте мир или перезапустите сервер.

| Папка | Что показывает |
| --- | --- |
| `01_minimal` | Новое исследование с двумя этапами |
| `02_edit` | Дополнение родного исследования без замены его полей |
| `03_category` | Новая вкладка, оформление, формула и перевод названия |
| `04_recipe_gate` | Собственное исследование и рецепт с условием полного завершения |
| `05_copy` | Независимая копия родной записи, правка иконки, родителя и первого этапа |

Примеры используют разные новые ID и могут работать вместе. Каждый из них
также работает отдельно с обязательными зависимостями аддона.
Не копируйте `standalone` целиком в `server_scripts`: установите только нужные файлы.

В корневых `server_scripts/research.js`, `server_scripts/edit_research.js`
и `client_scripts/research_lang.js` сохранён полный пример металлургии.
Он добавляет два исследования, свою вкладку, перевод и рецепт в тигле.

Копирование сохраняет текущее состояние источника, включая предыдущие правки
обработчиков, ключи перевода, родителей, siblings, addenda и неизвестные JSON-поля.
Ссылки не переназначаются на новый ID автоматически. Целевой ID должен быть новым.
Если хотите новое название и другой прогресс, задайте новый ID, `title()`
и нужные изменения явно. Прогресс игроков оригинала в копию не переносится.
